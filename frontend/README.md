# Frontend ownership

Build a WhatsApp-like web chat with a draft-form panel, missing-information list, loading/error states, explicit confirmation, and JSON download of the confirmed snapshot.

Use ../contracts/openapi.json and ../contracts/examples/session.json. Send requests only to the backend. Reuse client_message_id on retries and include expected_revision. Reload after a revision conflict. Disable editing after confirmation.

Choose and document the framework, install command, environment setup, development command, and relevant UI checks here before adding application code.
