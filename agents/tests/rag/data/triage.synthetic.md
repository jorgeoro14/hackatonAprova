# Synthetic application triage

Invented demonstration material for Example City; not a municipal policy,
employee answer or legal source.

## Completeness check

The fictional licensing clerk checks the site description before technical
review. If the site description is missing, the application returns to the
applicant for clarification. The technical reviewer then assesses the complete
application.

## Unknown information

No fee amount, deadline, tax calculation or legal authority is supplied here.
An answer requesting an exact fee or number of days must remain unknown.
